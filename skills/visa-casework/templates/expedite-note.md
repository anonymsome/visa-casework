# Template: expedite note

Attach **only** when the facts genuinely fit published expedite criteria.

A weak expedite ask stapled to a sound inquiry drags the whole request
toward "no." If the facts do not support one, say so directly to the user
and file the inquiry alone — that is the stronger filing, not the
consolation one.

## Prerequisite: an appointment must already exist

Before anything else, check this. State's published rule, verified
2026-09-14 on the U.S. Mission to India's visa page:

> "You must already have a confirmed interview appointment date in order to
> request an expedited appointment."

**If the user has no appointment, there is no expedite to request**, and this
template does not apply. Do not attach it, and do not let the user spend
effort on a request the system will not accept. Say so plainly — and note
that the inability to even ask is itself the strongest line in the main
request. See `references/framing.md`.

Also tell them not to cancel an existing appointment while an expedite
request is pending; the same page warns against it explicitly.

## Criteria, roughly

Posts publish their own criteria and they vary, so check the specific post's
page rather than relying on this list. Broadly, expedites are considered for:

- **Urgent medical** — the applicant's own treatment, or travel to a
  seriously ill or dying immediate family member.
- **Funeral / death** of an immediate family member abroad.
- **Urgent business or academic travel** with a hard, documented deadline —
  a conference presentation, a program start date, a job requirement.
- Occasionally, **prolonged separation** from immediate family, though this
  is the weakest category and is often declined.

Ordinary hardship, a long wait alone, or general inconvenience does not
qualify. Neither does a deadline the applicant set themselves.

Expedites are denied often, including well-documented ones. Say so before
the user pins hope on it.

## Expedite request — supporting note

**Applicant:** [FULL NAME]
**Post:** [CONSULATE/EMBASSY, CITY]
**Visa category:** [CATEGORY]
**Currently scheduled appointment:** [DATE, or "none available"]

**Basis for expedite request:** [ONE OF THE CRITERIA ABOVE, named plainly.]

**Circumstances:**
[THE FACTS. Who, what, when. For a medical basis: the family member, the
relationship, the diagnosis, when it began, current state. For a funeral:
who died, when, when the service is. For a deadline: what it is, what
document sets it, what is lost if it is missed. Dates, not adjectives.]

**Documentation available:**
[WHAT THE USER ACTUALLY HAS — physician's letter, death certificate,
conference acceptance, employer letter, program start letter. List only what
exists. If something is obtainable but not yet in hand, say when.]

**Consequence if not expedited:**
[CONCRETE. What is lost, and when. A date that passes is stronger than a
condition that persists.]

---

## Checks

- The basis is one of the published criteria, named, not a paraphrase that
  gestures at one.
- Every fact traces to intake.
- Documentation listed is documentation that exists.
- No identifiers — those go on the form.
- The user has been told expedites are frequently denied.
